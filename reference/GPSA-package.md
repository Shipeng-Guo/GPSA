# GPSA: Gene-set Perturbation Signature Analysis

GPSA provides fast similarity search over large-scale perturbation
signature databases using cMAP/GSEA-style rankZ semantics. It supports
single gene-set queries, up/down bidirectional queries, multi-channel
event definitions, batch queries, and vector-based full geneList
searches. HDF5-based storage enables memory-efficient querying with
optional preloading for maximum speed (~0.15s per query in memory mode).
